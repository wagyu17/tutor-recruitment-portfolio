# Campus Tutor Recruit

大学生の家庭教師採用サイト風ポートフォリオです。ココナラ等の求人サイト構築案件に応募する際、UI/UX設計・応募導線設計・CV改善のサンプルとして提示する想定で作成しています。

## 見せたいポイント

- 求職者が応募前に知りたい情報をファーストビューから短い導線で確認できる構成
- 応募率向上を意識したCTA、募集要項、選考フロー、FAQの配置
- スマホ閲覧でも条件確認と応募導線が崩れないレスポンシブ設計
- Webディレクター兼フルスタックエンジニアとして、情報設計から実装まで対応できること

## 使い方

`index.html` をブラウザで開くだけで確認できます。

応募文では以下のように説明できます。

> 大学生家庭教師の採用サイトを想定し、応募者が不安なくエントリーできるよう、募集条件・仕事内容・選考フロー・FAQを整理した採用LPを制作しました。応募導線、CTA配置、スマホ表示での読みやすさを重視しています。
